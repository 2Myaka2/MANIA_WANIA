# MANIA: все девять траекторий Егора

Нужны Linux, Bash, Git, Python 3.11 или новее с `venv`, доступ к репозиторию и
пакетам Python. Установите MANIA и запустите из checkout ветки `FAIR`:

```bash
git clone https://github.com/2Myaka2/MANIA_WANIA.git
cd MANIA_WANIA && git checkout FAIR
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[md]"
./run_egor_all.sh /path/to/Egor /path/to/results
```

Замените два пути своими. Первый — каталог с исходными файлами Егора: PSF,
CONF, OUT, XSC, DCD и `toppar/`. Сохраните согласованные имена и вложенный
`dcd/` для соответствующих запусков. Скрипт выбирает **0SS/1SS/2SS × r1/r2/r3**
сам; при отсутствии файла укажет траекторию и точный ожидаемый путь.
Каталог результатов должен находиться отдельно от входного: ни один не должен
содержать другой. Дополнительный архив для запуска не нужен.

**Подготовка и расчёт — тяжёлые операции. На кластере запускайте эту команду
внутри выделенного вычислительного задания/на вычислительном узле, а не на
login/управляющем узле.** Выделение ресурсов оформляется по правилам вашего
кластера; скрипт не отправляет задания планировщику.

Входной каталог должен допускать запись и создание жёстких ссылок. Скрипт
создаёт там `.mania_egor/` с подготовленными траекториями и служебными файлами;
исходные DCD не копируются и не меняются. Нужен диск для девяти полных
подготовленных DCD и результатов. Скрипт проверяет оценку размера подготовки
плюс запас 12 GB, но не резервирует место и не предсказывает размер контактов.
Во время работы не меняйте и не перемещайте входные файлы; проверьте стабильность UTC/NTP.

При первом запуске, **до подготовки**, скрипт покажет девять строк:
**0SS/1SS/2SS × r1/r2/r3 → DCD / PSF / CONF / OUT / XSC**.
Проверьте, что каждый исходный DCD действительно относится к указанному PSF
и запуску. DCD не содержит меток атомов: одного совпадения их числа недостаточно.
Введите имя проверившего, примечание и **`y`**. Вы подтверждаете только
соответствие исходных файлов запуску, а не PBC, подготовленные кадры, контакты
или QC. Пустой ответ или `N` останавливает запуск до подготовки.

Подтверждение сохраняется для точного набора файлов. После него скрипт готовит
все траектории и проверяет их автоматически. Если все проверки пройдены,
он запускает расчёты **без дополнительных вопросов**. При ошибке он останавливается,
сохраняет свидетельства и указывает траекторию и причину; обхода проверки нет.

После одобрения скрипт проверяет входы ещё раз и последовательно считает
**5–100 ns, шаг 200 ps, окна 2 ns через 1 ns, обе границы включены**.
Полный набор даёт 476 отсчётов и 94 окна на траекторию, по 11 отсчётов в окне
при полной доступности. Агрегация и публикация сюда не входят.

При сбое сохраните всё: вывод назовёт траекторию, причину и число завершённых
из девяти. Повторите ту же команду: завершённые результаты проверяются и
используются повторно; незавершённая попытка сохраняется, а расчёт начинается
в новой попытке. Продолжения расчёта контактов с середины нет.
При неизменных исходных файлах
повторного подтверждения не будет — запуск может продолжаться без клавиатуры,
в том числе в пакетном задании. После `N` повторный запуск снова попросит согласие.

Если любой исходный файл изменился или пропал, скрипт остановится до подготовки
и потребует нового явного подтверждения. Старое подтверждение не заменяется.
Сохраните прежние результаты; восстановите согласованные входы или согласуйте
новый набор с Андреем. Для нового набора укажите новый каталог результатов:
тогда появится новое раннее подтверждение. Изменённые PSF/CONF/OUT/XSC также
должны соответствовать согласованным данным запуска в checkout.

Передайте Андрею весь каталог результатов и `.mania_egor/` из входного каталога.
Они содержат подготовленные DCD, подтверждения, точную версию кода, команды,
логи и коды выхода. Сохраняйте структуру каталогов и исходные файлы.
Подробности: [интерфейс](egor_production_interface.md).
