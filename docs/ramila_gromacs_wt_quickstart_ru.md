# Черновик: запуск WT GROMACS в Colab

Среда запуска — **Colab**. Объём работы: только WT, **NORM и TUMOR,
по три реплики**. T330M исключён.

Это предварительная инструкция, ещё не готовая к передаче для рабочего запуска.
Подготовка координат и реальный технический тест на участке **5–8 нс**
с расчётом контактов и проверкой повторного запуска пока не выполнены.

## Подготовка исходных файлов

Сохраните структуру папок `NORM/replica 1` … `TUMOR/replica 3`.
Дождитесь полного завершения загрузки и записи исходных файлов.
Имена пяти итоговых XTC пока не подтверждены; подтверждено только имя
для **TUMOR/r2: `md_rep2_full.xtc`**. Не переименовывайте остальные файлы
по предположению. Пока имена не установлены и нужные файлы отсутствуют,
предварительная проверка остановит запуск.

Используйте локальное хранилище Colab и заранее проверьте свободное место.
Необходимый объём для исходных, подготовленных и временных файлов ещё
предстоит измерить в реальном тесте. Подключённый Google Drive сам по себе
не заменяет локальное рабочее хранилище.

## Предварительный запуск

В подготовленной папке проекта, с Python 3.11 или новее:

```bash
python3 -m pip install -e .
./run_gromacs_wt_all.sh /path/to/WT /path/to/results
```

Замените пути на папку исходных файлов и отдельную папку результатов;
обе должны быть доступны для записи. Проверьте показанное соответствие
условий, реплик и файлов. Если программа запросит подтверждение, вводите
его только после проверки полностью загруженных исходных данных.
**Вручную заполнять JSON или вводить хеши не нужно**: контрольные суммы
вычисляются автоматически.

Код завершения `1` означает ошибку предварительной проверки или подтверждения.
Код `3` означает лишь завершение проверки исходных файлов: подготовка координат
ещё не проверена на реальном XTC. **Это не успешный производственный расчёт**;
контакты на этом этапе не рассчитываются.

Перед рабочим запуском ещё нужны подтверждение оставшихся имён XTC,
проверка координат и реальный тест 5–8 нс. Готовность к передаче Рамиле
пока не подтверждена.
