through `--authority-input`; no assessment defaults are provided.

`authoritative_rmsd_assessment.json` uses the existing strict
`ReplicaReviewQCEvidence` adapter and `RMSDDriftAssessment`. Its artifact evidence

decision-resolution type. Clean hard/review PASS produces an automatic available
decision under the accepted workflow; the human reviewer remains in the bound
assessment evidence, while the decision's manual-review fields remain null.

Before QC, the helper creates explicit condition-bound canonical copies. Complete
model equality after removing only the condition change proves that all
scientific fields remain identical to accepted source science. Original inputs
are preserved byte for byte. The aggregation template is a required technical
input to Stage 32, not a production availability decision. The actual Stage 31

`run_replica_aggregation`. Its sources are frozen by path, SHA256 and row count
after QC and checked again after aggregation.

The independent n=1 check uses the frozen canonical source records directly,
without calling the production aggregator. It checks source denominators,
identity/window population, all exported aggregate fields, one contributing
replica, and null standard deviation. It does not substitute zero for missing
scientific evidence.

to this topology, and no authoritative aggregation correspondence is supplied.
Stage 31 supports protein-only input; Stage 33 supports empty specialised
aggregate tables for absent aggregate families. B.4 per-replica canonical science
is preserved and is not replaced with fabricated empty science.
