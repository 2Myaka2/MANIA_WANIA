# Запуск Ramila GROMACS в Colab

Нужны все 12 окончательных XTC, соответствующие TPR/MDP/LOG и отдельное место
для результатов. Источники: WT `eqmd_rep100ns_09_2026` (100 нс) и T330M
`T330M_30ns_09_2026` (30 нс). Каталоги сохраняются как `replica 1` и т. д.
Имена XTC: `md_repN_full.xtc` для WT, `t330m_repN.xtc` для T330M.
Исторические траектории не заменяют эти файлы.

## 1. Получить точную версию и установить

Откройте Colab и выберите среду с Python 3.12 (например, версию 2026.07).
Тег создан локально и не отправлен в GitHub. Переданный файл
`ramila-production-v1.bundle` содержит точную принятую версию; загрузите его:

```python
from google.colab import files
files.upload()  # выберите ramila-production-v1.bundle
```

Затем выполните в отдельной ячейке:

```bash
%%bash
set -euo pipefail
cd /content
git clone https://github.com/2Myaka2/MANIA_WANIA.git
cd MANIA_WANIA
git fetch /content/ramila-production-v1.bundle \
  refs/tags/ramila-production-v1:refs/tags/ramila-production-v1
git checkout --detach ramila-production-v1
git rev-parse HEAD
python --version
python -m pip install 'numpy==2.0.2' '.[science]'
mania --version
```

Сравните показанный SHA с итоговым отчётом. Conda не нужна. Требуется Python
не ниже 3.11; установка проверена отдельно в чистой среде Linux с Python 3.12.

## 2. Подключить исходное хранилище

```python
from google.colab import drive
drive.mount('/content/drive')
```

## 3. Один раз подтвердить источники

Подготовьте пути к корню, содержащему `WT/` и `T330M/`, и к отдельному выходному
каталогу. Пример использует Google Drive; выберите хранилище с достаточным
объёмом и временем работы для полной подготовки. Временные координаты также
пишутся в выходной каталог. MANIA автоматически оценивает место до подготовки.

```python
import os, sys, subprocess
from pathlib import Path
SOURCE_ROOT = '/content/drive/MyDrive/Ramila'
OUTPUT_ROOT = '/content/drive/MyDrive/Ramila_MANIA_results'
os.chdir('/content/MANIA_WANIA')
sys.path.insert(0, 'tools')
from run_ramila_gromacs import init
init(Path(SOURCE_ROOT), Path(OUTPUT_ROOT), input_fn=input)
```

Проверьте все 12 строк XTC → TPR → MDP → LOG. Затем введите своё имя,
краткую заметку проверки и `y`. Это подтверждение только соответствия исходных
траекторий наборам запусков. PBC, контакты и QC проверяются отдельно автоматически.
Хеши вычисляются программой; вручную их вводить не нужно. При `N` подтверждение
не сохраняется. После изменения исходных файлов продолжение блокируется;
сохранённое подтверждение нельзя незаметно заменить.

## 4. Запустить одну траекторию

```python
subprocess.run(
    ['./run_ramila_gromacs_one.sh', SOURCE_ROOT, OUTPUT_ROOT,
     'gromacs_wt_norm_r1'], cwd='/content/MANIA_WANIA', check=True)
```

Идентификаторы имеют вид `gromacs_wt_norm_r1` или `gromacs_t330m_tumor_r3`:
вариант `wt`/`t330m`, условие `norm`/`tumor`, реплика `r1`/`r2`/`r3`.
Для последовательного запуска группы замените команду на
`run_ramila_wt_all.sh`, `run_ramila_t330m_all.sh` или
`run_ramila_gromacs_all.sh` и передайте только два корневых пути.
Параметры времени, окон и контактов уже заданы; JSON редактировать не нужно.

Полная подготовка сохраняет всю временную ось в XTC:4:
разворачивание связанных фрагментов → центрирование белка → оборачивание целых
фрагментов. Внутренний MIC выключен. После подготовки выполняются белковый граф,
отдельные липидные и гликановые слои, сохранение покадровых наблюдений, строгая
валидация и точное восстановление CSV. Повторный запуск проверяет и использует
завершённый результат. Незавершённые попытки сохраняются под отдельными номерами.

Небольшие однозначные пропуски остаются пропусками: нет интерполяции или
подстановки соседних кадров; они не входят в знаменатель occupancy и разрывают
эпизоды. При разрешении менее 95% ожидаемых производственных отсчётов QC
завершается ошибкой. Дубли и обратный ход времени блокируют запуск.

## 5. Сохранить и передать результаты

Сохраните весь `OUTPUT_ROOT`, включая подтверждение источников, provenance,
отчёты подготовки, `preprocessing/`, покадровые наблюдения и отчёты replay.
Для проверки можно отдельно передать компактные отчёты и CSV; многогигабайтные
XTC не включайте в небольшой архив. Не удаляйте незавершённые попытки при ошибке.
Агрегация реплик выполняется позже, после производственного QC и нужных проверок.

Полные биологические аннотации Ramila пока **PENDING** для всех четырёх систем.
Наблюдения из TPR не заменяют подтверждение владельца. Контакты и канонические
таблицы доступны; аннотированные публикационные результаты ожидают этих метаданных.
